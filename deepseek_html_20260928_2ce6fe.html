Команды

Полезные бинды

Клик по кнопке — команда копируется в буфер. Вставь в консоль (F1) и нажми Enter.

❄ Важно: после ввода всех биндов напиши в консоли writecfg — иначе они сбросятся после перезахода.
Автобег (на Q)
bind q forward;sprint
Автоатака (на Z)
bind z attack
Автоатака + присед
bind z attack;duck
Быстрый лут (Mouse4)
bind mouse4 +hoverloot
Быстрый Alt (обзор)
bind alt +altlook
Быстрое лечение (слот 3)
bind 3 +slot3;+use
Очистка кэша (на J)
bind j gc.collect; pool.clear_assets; pool.clear_memory; pool.clear_prefabs; gc.alloc
Combat log (на F2)
bind f2 client.consoletoggle; combatlog; client.ping
Фонарик при прицеле
bind mouse1 +lighttoggle
Быстрый зум (Mouse3)
bind mouse3 +graphics.fov 90;+graphics.hud 1;graphics.fov 70;graphics.hud 0
Производительность

Оптимизация графики

Меньше картинки — больше FPS и видимости врагов.

🚫 Отключить

  • Тени — Off / 0
  • Облака — Off
  • Трава: тени и смещение — Off
  • Отражения воды — Off
  • Motion Blur — Off
  • Глубина резкости — Off
  • Виньетка — Off
  • Max Gibs — 0

✅ Оставить

  • Дальность прорисовки — 1600
  • NVIDIA Reflex — On + Boost
  • FOV — 90
  • Анизотропная фильтрация — 8x
  • Текстуры — High
  • V-Sync — Off

⚙️ Команды

  • grass.distance 0 — убрать траву
  • grass.on false — выключить траву
  • client.headlerp 5 — лучше стрельба
  • gc.buffer 4096 — память под кэш
  • fps.limit 0 — снять лимит FPS
  • graphics.shaderlod 1 — упростить шейдеры
Каждый заход

Сессионные команды

Вводи один раз при заходе через F1 — убирают инерцию, чинят стрельбу, дают высокий прыжок.

client.headlerp_inertia false; gc.buffer 4096; client.headlerp 5; gc.incremental_milliseconds 1; physics.steps 60
Прокачка

Советы новичкам

Мелочи, которые заметно улучшают игру.

💾 Сохраняй конфиг

После настройки введи writecfg — иначе всё сбросится.

🎯 Настрой слоты

Разложи оружие и аптечки по слотам 1–6. В бою секунды решают.

🔊 Звук важнее картинки

Настрой звук так, чтобы слышать шаги за 30+ метров.

🗺️ Знай карту

Мониторинги ресурсов помогут быстрее прогрессировать после вайпа.

⚡ Кэш помогает

Если FPS проседает — gc.collect или бинд на J.

🖱️ Чувствительность

Привыкай к одной чувствительности и не меняй. Стабильность важнее.
